# Snake Raja 🐍

A high-performance, real-time 3D multiplayer snake battleground built with pure **HTML5**, **CSS3**, **JavaScript (ES6+)**, **Three.js**, and **Socket.IO**.

## 🌟 Features
- **Pure Web Stack (100% HTML5 / CSS3 / JavaScript)**: Zero build steps, blazing fast startup, and lightweight execution.
- **Real-Time 3D Multiplayer**: Powered by Three.js WebGL and low-latency Node.js Socket.IO server.
- **Smartphone-First Cyberpunk UI**: Luxury glassmorphism HUD, 360° touch steering virtual joystick, turbo boost thruster, and responsive safe-area layout.
- **Champions & Avatar Head Customization**: Serpent Raja 🐍, Shadow Reaper 💀, Cyber Mech 🤖.
- **Dynamic Loot & Power-ups**: Life Cores (❤️), Armor Shields (🛡️), Plasma Blades (⚔️), and Energy Cores (⚡).
- **Match Victory & Quests System**: First to 250 PTS wins the Raja Champion crown 👑, with 8 active quests and XP progression.
- **On-Device Storage**: Saved career stats, high scores, win rate %, and multi-profile login directly on device.

## 🚀 How to Run Locally

**Prerequisites:** Node.js v18+

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🎮 Controls
- **Mobile Touch**: Left Thumb = Turbo Boost Thruster | Right Thumb = 360° Virtual Steering Joystick.
- **Keyboard (Desktop)**: **A / D** or **Left / Right Arrows** to Steer | **W / Space / Up Arrow** for Turbo Boost.
